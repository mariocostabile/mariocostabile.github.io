# Product

## Platform

web

## Stack

Static HTML/CSS/vanilla JS, no framework. A small Node script runs inside a GitHub Action, fetches the pinned repos via the GitHub GraphQL API and writes them to a JSON file; the same workflow deploys to GitHub Pages. Repo: `mariocostabile/mariocostabile.github.io` → https://mariocostabile.github.io/

## Users

Recruiters and tech leads at companies offering internships or jobs, deciding in a few minutes whether to call Mario for an interview.

## Product Purpose

Personal portfolio of Mario Costabile: who he is, what he studied, what he can use, and his real GitHub work, always current without manual edits. Success = a recruiter leaves with a clear, credible picture and a way to contact him.

## Positioning

Breadth, not a specialism. Mario explicitly does not want to look like an expert in one niche (e.g. anomaly detection) — the projects span AI/computer vision, full-stack web, mobile, and Telegram bots, and the site must read as a versatile, reliable junior who finishes what he starts and keeps learning.

## Operating Context

- Projects section = the repos pinned on github.com/mariocostabile, in pin order, refreshed by the Action (schedule + push). Button "Vedi tutti i repository" → github.com/mariocostabile?tab=repositories.
- Avatar = GitHub avatar (auto).
- A colleague on the same degree course (giovannicrs.github.io) has a similar portfolio; recruiters may see both, so the look must be clearly distinct from his (dark, blue accent, Space Grotesk/Inter, cards).

## Capabilities and Constraints

- Bilingual IT/EN with a toggle. Repo descriptions stay in whatever language they have on GitHub.
- Light + dark, following the system preference.
- CV: not available yet. A placeholder location in the repo where Mario drops the PDF later; the download button only appears once a real CV exists.
- No phone number on the site.
